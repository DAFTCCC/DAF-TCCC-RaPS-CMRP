# UPLOAD THIS REPOSITORY FOR THE APK

Use this package for the Android build only.

Upload the **contents of this folder** to the root of the GitHub repository. Do not upload this ZIP as a single repository file.

Then run:

**GitHub -> Actions -> Build FieldReady Android APK -> Run workflow**

Expected artifact:

`FieldReady-Competency-Study-v4.1.3-APK`

The final APK inside that artifact is:

`FieldReady-Competency-Study-v4.1.3.apk`
